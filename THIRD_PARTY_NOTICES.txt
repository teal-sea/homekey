Third-party notices

The only third-party code this app ships is the amp engine, served from /nam/:
nam-worklet.js and nam-engine.wasm. scripts/copy-engine.mjs copies them there
from node_modules at build time, with the package's LICENSE and this file.

They come from the npm package neural-amp-modeler-wasm 3.0.7 by TONE3000
(https://github.com/tone-3000/neural-amp-modeler-wasm), MIT licence, copyright
2026 TONE3000; its licence text is LICENSE next to this file in /nam/.

That package's WebAssembly build compiles in the code listed below. Checked
2026-11-08 against the package's source repository at its 3.0.7 commit
(ea8dc285462d6cedd982691b9f090cd03dac04a2; wasm/CMakeLists.txt compiles every
.cpp under NeuralAmpModelerCore's NAM/, with Eigen and nlohmann/json on the
include path) and against the NeuralAmpModelerCore submodule that commit pins:
tag v0.5.4, commit 1f42f88535884450104b8711d7595019afa0495b.

Not compiled in: AudioDSPTools. NeuralAmpModelerCore v0.5.4 lists it as a
submodule, but no file under NAM/ includes it and the wasm build does not put
it on the include path.
